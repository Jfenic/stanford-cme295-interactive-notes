Guía de mantenimiento

Añadir apuntes nuevos es muy sencillo.

La portada se actualiza desde un pequeño catálogo. No hace falta modificar su diseño ni instalar dependencias.

1 · Sube el HTML

Guarda los nuevos apuntes como clases/clase-02.html. Si partes de un archivo de la IA, puedes usarlo completo. Añade un enlace a la portada:

<a href="../index.html">← Volver al índice</a>

2 · Actualiza el catálogo

En data/clases.js, localiza la clase 2 y cambia su entrada por algo como esto:

{
  numero: 2,
  titulo: 'Título de la segunda clase',
  descripcion: 'Resumen breve de la clase.',
  temas: ['Tema A', 'Tema B'],
  archivo: 'clases/clase-02.html',
  publicada: true,
  laboratorio: false
},

Activa publicada: true solo cuando el archivo HTML esté subido, para evitar enlaces rotos.

3 · Guarda los cambios en GitHub

Sube los dos archivos modificados (el HTML y data/clases.js) a la rama desde la que publicas GitHub Pages. En cuanto se despliegue, aparecerá la nueva clase en la portada.

Para comenzar desde cero

En el archivo README.md del repositorio están los pasos completos de publicación con GitHub Pages. También puedes copiar plantillas/plantilla-clase.html para escribir una clase desde cero.

Estos apuntes se generan con ayuda de IA y deben revisarse con fuentes originales. El proyecto no está afiliado a Stanford University.
